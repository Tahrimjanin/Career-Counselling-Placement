# Screen-by-screen user manual source

1. **Home**: Create account, Sign in, Start your career journey; live counts, advisors, open opportunities, FAQs, Contact, Privacy, Terms.
2. **Sign in / Create account**: Workspace (Student, Career Advisor, Admin, Recruiter), Email address, Password; registration adds Full name, Confirm password, Department for students and Company name for recruiters. Register creates the account. Staff see Account awaiting approval with Check approval status / Sign out. No university email requirement.
3. **Dashboard**: Welcome, completion and readiness remain separate. Sidebar opens each workspace. Header name links to My profile; bell opens Notifications.
4. **My profile**: Profile image → Choose JPG, PNG or WebP (maximum 2 MB) → Upload image / Remove image. Student eight-step wizard uses Save & continue and the Required fields checklist. Staff save personal/contact details with Save progress.
5. **My advisor / Advisor allocation**: students submit preferences; Admin approves allocation and manages capacity. Preferences alone never assign an advisor. My Students gives advisors their active assigned students.
6. **Counselling sessions**: request, confirm, reschedule, cancel and feedback according to role. Career plan manages goals/milestones. Times display Dhaka; persistence is UTC.
7. **CV Builder / CV Review**: build/upload a CV, submit for review, advisor approves or requests changes. Approved versions remain identifiable on applications; uploaded files are private.
8. **Find Opportunities / Post Opportunity / Opportunity approval**: recruiter company must be verified; new posts wait for Admin approval. Students search/filter/save/match and choose Check eligibility / Apply.
9. **Applications / Application Queue / Candidates**: View application details shows application ID, CV, cover note and Status history. Submitted to Admin is distinct from Forwarded to company. Admin requests changes, rejects or approves/forwards. Recruiter then shortlists/rejects and schedules interviews.
10. **Interviews / Offers / Placement records**: recruiter schedules and records feedback; makes an offer with start date and expiry. Student accepts/declines; acceptance records placement. Admin sees Placement records.
11. **Notes**: personal notes; advisor private notes remain scoped to assigned students and are not sent to recruiter.
12. **Notifications**: Show all/unread/deadlines/interviews; Mark as read / Mark all as read; Open workspace. Students set Follow-up reminders using Application ID and Repeat every (days); Remove reminder cancels it.
13. **Users** (Admin): Create an account with temporary password or approve public signup. Account status filter → Pending approval → Approve account. Activate, Suspend, Reset password. Temporary passwords require change; suspension revokes tokens.
14. **Companies** (Admin): create company; verify/unverify. Signup-created companies start unverified.
15. **Reports**: optional From date / To date → Apply dates. Applicants, Placed students, Placement rate, Applications; Application funnel, Advisor workload, Top skills. Export CSV uses the same filters.
16. **Audit log**: Filter action and Decision details, pagination. Settings: Academic session, Default advisor capacity, Contact email/phone/address, Privacy notice, Terms of use → Save. Contact/policy edits appear publicly.
